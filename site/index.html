BlumScript

Универсальный компилируемый язык: английские ключевые слова для низкого порога входа и полный доступ к памяти для системного программирования.

BlumScript компилируется напрямую в машинный код x86-64 и PE32+ .exe: без C, без ассемблера, без LLVM и без внешнего линковщика. Никакой виртуальной машины — только нативные инструкции. Один и тот же язык подходит и для прикладного кода, и для низкоуровневых задач.

Высокоуровневый стиль

  • let, var, вывод типов
  • func, if, while, for
  • структуры и строки

Низкоуровневый стиль

  • указатели *T, &, *
  • malloc/free, sizeof
  • cast<T>, asm { ... }
  • вариативные функции func f(a: int, ...)
Все примеры на сайте можно запускать прямо в разделе Песочница (поддерживается подмножество: переменные, выражения, условия, циклы, функции, печать).

Установка

Компилятор написан на Rust и генерирует машинный код сам. Нужно:

  • Rust и cargo;
  • Windows x64 для запуска собранных .exe.

Сборка из исходников

cd blumscript_rust
cargo build --release

Бинарник появится в target\release\blumsc.exe.

Установщик Windows

Запустите installer\install.bat (или install.ps1). Скрипт:

  • соберёт компилятор, если бинарника ещё нет;
  • скопирует blumsc.exe, документацию, примеры и этот сайт в %LOCALAPPDATA%\BlumScript;
  • добавит bin в пользовательский PATH;
  • создаст uninstall.ps1 для удаления.
installer\install.bat
:: после установки откройте новый терминал
blumsc run hello.blm

Первая программа

Создайте файл hello.blm:

func main() -> int {
    print("Hello, BlumScript!");
    return 0;
}

Соберите и запустите:

blumsc run hello.blm

Вывод:

built: hello.exe
Hello, BlumScript!
print печатает аргументы без разделителей и добавляет перевод строки. Чтобы получить пробел, добавьте его в строку: print("x = ", x).

Переменные и типы

Объявление с инициализатором. Тип можно указать явно или вывести:

let x: int = 10;     // неизменяемая по замыслу
var y: int = 20;     // изменяемая
let z = 5;           // тип выведен: int

Область видимости — блок { }. Верхнеуровневые let/var становятся глобальными переменными и инициализируются в начале main.

Операторы

Арифметика

let a = 10 + 3 * 2;   // 16
let b = 3.5 / 2.0;    // 1.75
let c = a % 5;        // 1

Сравнения и логика

let ok = a >= 15 and a != 7;
let no = not ok;
let any = ok or no;

Битовые операции

let mask = 1 << 4;    // 16
let inv  = ~mask;
let x    = 0xF0 | 0x0F;

Приоритет (от низкого к высокому)

  2. or, ||
  3. and, &&

  5. ^
  6. &
  7. ==, !=
  8. <, >, <=, >=
  9. <<, >>
  10. +, -
  11. *, /, %
  12. унарные -, not, ~, *, &

Условия и циклы

if / else

if (x > 0) {
    print("positive");
} else if (x < 0) {
    print("negative");
} else {
    print("zero");
}

while

var i: int = 0;
while (i < 10) {
    print(i);
    i = i + 1;
}

for

for (var i: int = 0; i < 10; i = i + 1) {
    print(i);
}

break / continue

for (var i: int = 0; i < 100; i = i + 1) {
    if (i == 5) { break; }
    if (i % 2 == 0) { continue; }
    print(i);
}

Функции

func add(a: int, b: int) -> int {
    return a + b;
}

func greet(name: string) {
    print("Hello, ", name);
}

Параметры типизированы. Возвращаемый тип указывается через ->; если его нет — void. Поддерживается рекурсия.

func fact(n: int) -> int {
    if (n <= 1) {
        return 1;
    }
    return n * fact(n - 1);
}
Точка входа — func main() -> int. Компилятор создаёт PE-entry, который инициализирует глобалы, выполняет операторы верхнего уровня, вызывает main и завершает процесс через ExitProcess.

Структуры

struct Point {
    x: int;
    y: int;
}

func main() -> int {
    var p: *Point = cast<*Point>(malloc(sizeof(Point)));
    p->x = 10;
    p->y = 20;
    print("x=", p->x, " y=", p->y);
    free(p);
    return 0;
}

Доступ по значению — obj.field, через указатель — ptr->field. Компилятор сам выбирает . или -> по типу базы.

var a: Point;
// ...
print(a.x, a.y);

Указатели и память

Адрес и разыменование

var n: int = 5;
var p: *int = &n;    // адрес n
*p = 42;             // запись по адресу
print(n);            // 42

malloc / free

var buf: *int = cast<*int>(malloc(sizeof(int) * 16));
buf[0] = 1;
buf[15] = 16;
free(buf);

Арифметика указателей

*(arr + 1) = 2;   // эквивалентно arr[1] = 2
Границы не проверяются. Это C-семантика: ответственность за корректность лежит на программисте.

sizeof и cast

let bytes: int = sizeof(Point);
var p: *Point = cast<*Point>(malloc(bytes));

Импорты и asm

Модули

import "utils.blm";

Импорт раскрывается рекурсивно относительно текущего файла; расширение .blm добавляется автоматически. Повторные включения игнорируются.

Inline-ассемблер

asm {
    mov rax, 42
    mov [n], rax        // локальная переменная
    add qword [counter], 1
    mov rcx, [n]
    call twice          // вызов функции BlumScript
loop_start:
    dec rax
    jnz loop_start
}

Внутри asm { ... } работает текстовый ассемблер: мнемоники (mov, add, cmp, jmp/jcc, call, SSE-операции), локальные метки и доступ к переменным по имени — [local] превращается в [rbp-off], [global] — в rip-relative обращение к .data. Строка из одних hex-байтов по-прежнему копируется в .text дословно.

asm {
    48 c7 c0 2a 00 00 00   // mov rax, 42
    90 90                  // nop nop
}

Вариативные функции

func sumn(n: int, ...) -> int {
    var i: int = 1;
    var s: int = 0;
    while (i <= n) {
        s = s + va_int(i);
        i = i + 1;
    }
    return s;
}

Аргументы ... раскладываются по Windows x64 varargs ABI: позиционные слоты, дублирование float в целочисленные регистры, home space в прологе. Читаются через va_int(i) и va_float(i).
